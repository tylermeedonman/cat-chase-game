Cat Chase

Cat Chase is a p5.js game where the player controls a cat using the mouse cursor. The goal is to catch 10 mice. The mouse runs away whenever the cat gets close.

The main mechanic is chasing. The player moves the cat with the cursor, and the mouse reacts by trying to escape. This creates a dynamic where the player has to move quickly, predict the mouse's movement, and use the edges of the screen to trap it.

The aesthetic is playful and cartoon-like. The game uses simple shapes and a clear win condition so it feels like a small arcade game. I think people should play it because it is easy to understand, quick to try, and turns a simple chase mechanic into a fun cat-and-mouse interaction.
